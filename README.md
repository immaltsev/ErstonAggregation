# Агрегация обувной продукции в Mobile SMARTS

Проект итогового задания Cleverence на языке Erston. Решение автоматизирует упаковку маркированной обуви в коробки (ТУ1), а коробок — в паллеты (ТУ2).

## Возможности

- создание и продолжение сборки коробок;
- проверка DataMatrix, GTIN и серийного номера;
- автоматическое закрытие коробки по заданной глубине;
- упаковка локальных и серверных коробок в паллеты;
- загрузка содержимого паллет с сервера;
- просмотр и удаление набранных данных;
- выгрузка упаковок и марок в серверные таблицы;
- фиксация конфликтов повторного размещения марок.

## Требования

- Windows с установленной платформой Mobile SMARTS;
- Visual Studio Code;
- расширение Erston;
- товарный справочник с однозначно определяемыми GTIN.

Проект проверен с расширением Erston `0.9.0` и платформой Mobile SMARTS `4.0.2.52878`.

## Запуск

1. Откройте папку проекта в Visual Studio Code.
2. Выполните команду `Erston: Build and publish`.
3. Нажмите `F5`, чтобы собрать проект и запустить эмулятор ТСД.
4. Создайте документ типа «Итоговое задание».

## Структура

```text
src/
  app.erst                 обработчики приложения
  global.erst              поля документа и строк
  documents/
    core/                  тип документа и главное меню
    boxes/                 товары и коробки
    pallets/               паллеты и просмотр набранного
  metadata/                штрихкоды, настройки и таблицы
  operations/
    packages/              серверный реестр упаковок
    completion/            обработка завершения документа
.project/                  конфигурация Mobile SMARTS
docs/                      документация и проверки
```

Сгенерированная конфигурация после сборки находится в каталоге `output`.
