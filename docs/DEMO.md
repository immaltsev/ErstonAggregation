# Демонстрационный сценарий

Сценарий показывает полный цикл: товар → коробка → паллета → сервер.

## Подготовка

- в товарном справочнике есть товары для двух тестовых GTIN;
- глубина коробки установлена равной `2`;
- `0000001` отсутствует в серверной таблице;
- паллета `0011111` доступна для сборки.

## 1. Сборка коробки

1. Создать документ «Итоговое задание».
2. Выбрать «Товары в коробки».
3. Отсканировать коробку `0000001`.
4. Отсканировать DataMatrix A.
5. Убедиться, что товар сразу появился в списке и счётчик показывает `1/2`.
6. Отсканировать DataMatrix B.

Результат: второй товар сразу появляется в списке, счётчик достигает `2/2`, коробка автоматически закрывается и отображается красным.

## 2. Сборка паллеты

1. Вернуться в главное меню и выбрать «Коробки в паллеты».
2. Отсканировать паллету `0011111`.
3. Отсканировать коробку `0000001`.
4. Проверить появление коробки в списке «Коробки на паллете».
5. Повторно отсканировать `0011111`.

Результат: коробка привязана к паллете, список обновляется сразу, повторное сканирование закрывает паллету.

## 3. Просмотр результата

Открыть «Просмотр набранного» и выбрать:

```text
Паллета 0011111
└── Коробка 0000001
    ├── Товар A — серийный номер A
    └── Товар B — серийный номер B
```

Выбор товара открывает карточку с наименованием, GTIN и серийным номером.

## 4. Завершение

Выбрать «Выход» → «Завершить».

Результат: коробка `0000001` и обе марки записаны на сервер.

## 5. Проверка между сеансами

1. Создать новый документ.
2. Перейти в «Коробки в паллеты».
3. Отсканировать `0011111`.

Результат: `0000001` загружается с сервера и сразу отображается в содержимом паллеты.

Для демонстрации серверной коробки без родителя:

1. Создать на сервере коробку `0000003` с незаполненным полем `Родитель`.
2. Открыть паллету `0011111`.
3. Отсканировать `0000003`.

Результат: коробка находится по отдельной проверке существования, получает родителя `0011111` и появляется в списке паллеты.

Итоговое состояние сервера:

| Таблица | Результат |
|---|---|
| `ТранспортныеУпаковки` | `0000001` и `0000003` имеют родителя `0011111` |
| `Марки` | DataMatrix A и B записаны с коробкой `0000001` |
| `МаркиСОшибками` | пусто при отсутствии конфликтов |
