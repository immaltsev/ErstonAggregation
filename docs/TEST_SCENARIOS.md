# Тестовые сценарии

## Тестовые данные

| Объект | Значение |
|---|---|
| Новые коробки | `0000001`, `0000002` |
| Серверная коробка без паллеты | `0000003` |
| Серверная коробка на другой паллете | `0000004` → `0012222` |
| Несуществующая коробка | `0000099` |
| Паллеты | `0011111`, `0012222` |
| Марки | DataMatrix A и B с известными GTIN и разными SN |
| Неизвестная марка | DataMatrix с GTIN, отсутствующим в справочнике |

Перед проверкой серверные таблицы должны соответствовать указанным предусловиям, а известные GTIN — однозначно находиться в товарном справочнике.

## Основные сценарии

| ID | Приоритет | Проверка | Шаги | Ожидаемый результат |
|---|---:|---|---|---|
| TC-01 | P0 | Главное меню | Создать и открыть документ | Доступны пункты «Товары в коробки», «Коробки в паллеты», «Просмотр набранного», «Настройки», «Выход» |
| TC-02 | P1 | Настройка глубины | До сканирования товара установить глубину `2` | Значение сохранено; отображено подтверждение |
| TC-03 | P1 | Проверка глубины | Ввести `0`, затем добавить товар и снова открыть настройки | `0` отклонён; после добавления товара настройка недоступна |
| TC-04 | P0 | Новая коробка | Отсканировать `0000001`, затем марки A и B | Обе марки сразу появляются в списке; счётчик меняется `1/2` → `2/2`; коробка закрывается |
| TC-05 | P1 | Ошибочный тип ТУ | В окне коробки сканировать `0011111`; в окне паллеты — `0000001` | Показано сообщение о неверном уровне упаковки |
| TC-06 | P1 | Неверный товарный штрихкод | В коробке отсканировать EAN13 | Показано «Отсканируйте марку»; строка не создана |
| TC-07 | P1 | Неизвестный GTIN | Отсканировать неизвестную марку | Показано сообщение об отсутствующем или неоднозначном товаре |
| TC-08 | P1 | Повторная марка | Повторно отсканировать марку A | Открыта карточка существующей марки; дубль не создан |
| TC-09 | P1 | Удаление марки | Открыть карточку марки, нажать «Удалить», подтвердить | Строка удалена; неполная коробка доступна для продолжения |
| TC-10 | P1 | Очистка коробки | Открыть коробку из списка, нажать «Очистить коробку», подтвердить | Все строки коробки удалены; коробка исчезла из списка |
| TC-11 | P0 | Серверная коробка в сборке товаров | В «Товары в коробки» отсканировать `0000003` | Работа с коробкой запрещена, так как она уже зарегистрирована на сервере |

## Паллеты и сервер

| ID | Приоритет | Проверка | Шаги | Ожидаемый результат |
|---|---:|---|---|---|
| TC-12 | P0 | Коробка документа в паллете | Открыть `0011111`, отсканировать коробку документа | Коробка привязана к паллете и сразу отображается в списке |
| TC-13 | P0 | Содержимое серверной паллеты | В новом документе открыть `0011111`, содержащую серверные коробки | Ранее добавленные коробки сразу показаны в списке |
| TC-14 | P0 | Серверная коробка без паллеты | В `0011111` отсканировать `0000003` | Коробка найдена отдельной серверной проверкой, добавлена в паллету и отображена в списке |
| TC-15 | P0 | Несуществующая коробка | В паллете отсканировать `0000099` | Показано «Такой коробки нет ни в документе, ни на сервере» |
| TC-16 | P1 | Перемещение коробки | В `0011111` отсканировать `0000004`, подтвердить перенос с `0012222` | Родитель серверной коробки изменён на `0011111` |
| TC-17 | P1 | Отмена перемещения | Повторить TC-16 и отказаться | Родитель не изменён; коробка не добавлена |
| TC-18 | P1 | Закрытие паллеты | Повторно отсканировать текущую паллету | Паллета закрыта; открыт экран сканирования паллет |
| TC-19 | P1 | Смена паллеты | В открытой `0011111` отсканировать `0012222`, подтвердить | Первая паллета закрыта; вторая открыта без дополнительного сканирования |

## Просмотр и завершение

| ID | Приоритет | Проверка | Шаги | Ожидаемый результат |
|---|---:|---|---|---|
| TC-20 | P1 | Иерархический просмотр | Открыть «Просмотр набранного» и последовательно выбрать паллету, коробку, товар | Показана иерархия паллета → коробка → товар и карточка GTIN/SN |
| TC-21 | P1 | Временный выход | Набрать часть коробки, выбрать «Временно выйти», снова открыть документ | Строки сохранены; незакрытая коробка показана синим и доступна для продолжения |
| TC-22 | P0 | Завершение документа | Завершить непустой документ | Упаковки и марки записаны на сервер; документ завершён |
| TC-23 | P1 | Повторная серверная обработка | Повторно запустить обработку того же завершённого документа | Дубль марки в той же коробке не создаётся |
| TC-24 | P1 | Конфликт марки | Завершить документ с маркой, уже зарегистрированной в другой коробке | Запись удалена из `Марки` и добавлена в `МаркиСОшибками` |
| TC-25 | P1 | Пустой документ | Создать документ без строк и выбрать «Завершить» | Документ удалён без выгрузки на сервер |

## Критерий приёмки

Релиз считается готовым, если все сценарии P0 и P1 выполнены без блокирующих отклонений, а данные в интерфейсе совпадают с документом и серверными таблицами.
